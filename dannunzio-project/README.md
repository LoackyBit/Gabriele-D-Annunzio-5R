# Gabriele D'Annunzio - Il Vate

Un sito web completo e interattivo su Gabriele D'Annunzio, realizzato seguendo un design "Decadente" moderno.

## Descrizione Progetto
Questo progetto è una Single Page Application (SPA) che esplora la vita e le opere del Vate. Include:
- Una sezione Hero immersiva.
- Una chat integrata con un'IA personificata (Gemini).
- Un gioco interattivo "Riconosci l'Inganno" per distinguere testi reali da quelli generati dall'IA.
- Sezioni dedicate a Video e Poesia.

## Tech Stack
- **HTML5**: Struttura semantica.
- **CSS3**: Styling avanzato con CSS Variables, Flexbox, Grid e animazioni keyframe. Nessun framework esterno (Tailwind emulato con CSS vanilla).
- **JavaScript**: Vanilla JS per la logica del gioco, smooth scroll e gestione UI.

## Setup Locale
1. Clona il repository.
2. Apri `index.html` nel tuo browser.
3. Oppure usa un server locale (es. Live Server per VS Code) per testare le funzionalità complete.
